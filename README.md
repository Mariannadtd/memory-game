# Memory Game

Игра на поиск одинаковых пар портретов. Игрок открывает по две карточки и старается найти все восемь пар за минимальное количество ходов.

## Возможности

- случайное перемешивание 16 карточек перед каждой игрой;
- подсчёт ходов и найденных пар;
- блокировка поля во время показа несовпавшей пары;
- новая игра без перезагрузки страницы;
- сохранение десяти лучших результатов в `localStorage`;
- таблица лидеров с количеством ходов и датой;
- адаптивный интерфейс.

## Локальный запуск

Сторонние зависимости не требуются.

1. Клонируйте репозиторий.
2. Перейдите в папку проекта.
3. Откройте файл `index.html` в браузере.

Также проект можно запустить через расширение Live Server в Visual Studio Code.
